### What I learned

I wanted to check as much responsive as possible with the dev-tools.

But I was failing at screen sizes of 168px and smaller.

I wanted to correct myself, so I searched to make the texts wrap as much possible.

I found the MDN doc - [overflow-wrap](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/overflow-wrap) .

I used this declaration - `overflow-wrap: anywhere;` so that the words don't overflow their container.
