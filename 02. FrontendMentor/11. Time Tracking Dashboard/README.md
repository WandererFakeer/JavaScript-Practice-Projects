## Overview

This is a solution to the Time Tracking Dashboard on Frontend Mentor.

We can see the time tracked To-Dos by Daily, Weekly and Monthly timelines.

Just clicking on Daily, Weekly and Monthly will show the time of To-Dos of that particular timeline.

This is a screen-size friendly dashboard.
