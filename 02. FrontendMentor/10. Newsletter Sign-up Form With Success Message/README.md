## Overview

This is a solution to the Newsletter Sign-up Form With Success Message on Frontend Mentor.

After providing email, it checks if the provided email is a valid email address or not. 
If the provided email is not valid, it alerts the user to provide valid email.
If the provided email is valid, then it shows a success alert window.
